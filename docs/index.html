Git tracks lines.
awgit tracks code nodes.

When two agents edit the same function minutes apart, git records a tidy linear history and tells you nothing. awgit keys every edit to a stable node id, so that collision is a thing you can see — and, if you want, refuse.

Install

pip install "awgit[multilang]" # + TypeScript, Go, C#, 70 more extensions

What it actually does

Node identity that survives movement

A function that moves to the top of a file and has its body rewritten keeps its id. That single property is what makes node-level merge possible — without it, every reorder reads as a delete plus an add, and the merge is worth nothing.

Leases, so a collision is refused rather than discovered

awgit lease list                 # who is in this file right now
awgit lease acquire --staged     # claim what you are about to commit

With enforcement on, the pre-commit hook rejects a commit whose staged files you don't hold: no active lease covering: <path>. The identity is derived per session, so nothing needs configuring.

A graph, because the op-log is one

awgit graph                      # mermaid: files, nodes, who touched what
awgit graph --format json        # node/edge form for a graph store

Files render as subgraphs with their code nodes inside; a node two authors touched is drawn as a collision. That's the only part of the picture that means something is wrong.

What is proven, and what is not

Replayed against 1,833 real merge commits: every one the node engine could evaluate came back clean — no false conflicts. That proves it doesn't cry wolf on real history, which is the failure mode that would kill it on contact.

It does not yet prove superiority over git. Zero false positives also means zero cases where awgit rescued something git lost. The evidence that matters is the collision count above, and it is early and small. It grows on its own; the honest thing is to say so rather than dress it up.

awgit is a Python semantic VCS with a language-agnostic lease layer. With the multilang extra its node identity extends to 20+ languages; without it, non-Python files still get leases but no semantic diff. It reports which, rather than implying coverage it doesn't have.

The constellation

Three packages, three different questions about the same repository. awgit knows what changed and who is editing it. awgraph knows what the code is — symbols, call paths, what depends on what. aither-adk is the agent runtime that consumes both.

They are separate packages on purpose, and they consume each other rather than copying: aither-adk takes awgraph as a real dependency, and awgit's shared modules are generated from one source with a checker that fails on drift. Both of those exist because the alternative was tried — hand-copied trees drifted in 14 of 17 modules, and one of them silently lost a guard.
