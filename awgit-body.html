Git, with a world model on top

git knows which lines moved. awgit knows what a function is — who changed it, under a verified identity, and what it was before.

ops

Semantic edit-ops

Every commit becomes an EditOp keyed on stable node ids — only what changed, never the snapshot. The op-log is a differential index.

identity

Verified attribution

Every op records the actor and the box's verified GitHub identity. The op-log doesn't take anyone's word for who did what.

bodies

Content-addressed bodies

Node bodies stored by git-blob content address — any op reconstructs any body without the original blobs. Content addressing is dedupe.

merge

Node-granularity merge

Disjoint node sets merge clean by construction; real collisions escalate naming the exact function with both bodies.

leases

Leases

Heartbeat-renewed TTL — a vanished agent's leases free their targets on their own. Two agents with leases never collide.

sync

Differential sync

Teleport the ops a peer is missing, not the trees. Idempotent — a bundle applied twice converges. Bodies are pulled by hash.

Install

Python 3.10+ and git. The post-commit hook resolves a verified GitHub identity via gh — best-effort; capture never depends on it.

bash
# from source
git clone https://github.com/aitherium/awgit && cd awgit
pip install -e .

# set up
awgit init              # verify the actor — gh → verified GitHub login
awgit hooks install     # chained post-commit capture; preserves your hooks

# work
awgit status             # op-log: what changed, who, verified identity
awgit ledger --sha HEAD  # attribution record for this commit
awgit sync export -o delta.json   # hand the delta to a peer node
Ready for Claude Code / agents? Install the hooks, then follow the README or the awgit-claude-code skill for the after-commit workflow.
